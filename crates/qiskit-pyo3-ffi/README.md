# Qiskit bindings

Generated by Qiskit's `qiskit-bindgen-cli` from Qiskit 2.5.2, commit
[`c1c01ada399af13e495c27b9b22b4ff942bbad7e`](https://github.com/Qiskit/qiskit/tree/c1c01ada399af13e495c27b9b22b4ff942bbad7e).
The Rust source is unchanged.

The sole local patch widens the manifest's PyO3 upper bound from `<=0.28`
to `<=0.29`, to match GULPS's PyO3 0.29 dependency.
It is not yet upstream.

## Upgrade

Regenerate the bindings in a Qiskit checkout at the revision above:

```sh
git checkout c1c01ada399af13e495c27b9b22b4ff942bbad7e
cargo run -p qiskit-bindgen-cli -- generate-pyo3 \
  --cext-path crates/cext --output-path dist/rust/qiskit-pyo3-ffi
```

Copy the generated package into `crates/qiskit-pyo3-ffi`, keeping this README
and the license, and reapply the manifest patch above. Drop the patch when
upstream permits PyO3 0.29. The bindings must match the Qiskit version that
`pyproject.toml` requires.

To verify, compare the source with upstream and run `make test` and
`make lint` from the GULPS root. Check that the source distribution includes
the bindings and licenses listed in [MANIFEST.in](../../MANIFEST.in).
