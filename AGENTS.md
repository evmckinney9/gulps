# Project instructions

Read [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md) before changes to builds, dependencies, packaging, or release workflows. Keep contributor instructions in that file.

Because `crates/can_sandwich` is a separate Git repository, changes to the solver need their own commits. Before updating GULPS to use a new solver commit, run the build, test, and lint commands listed in [Upgrade the solver](.github/CONTRIBUTING.md#upgrade-the-solver).
